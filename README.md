# CRUD Web Application

## Overview

This project is a simple CRUD web application built with Node.js, Express.js, MongoDB, and EJS.

The application allows users to create, read, update, and delete data through a web interface.  
This project was created to practice backend development, server-side rendering, and database integration.

## Features

- Create new data
- Read stored data
- Update existing data
- Delete existing data
- Render dynamic pages using EJS
- Store and manage data with MongoDB

## Technologies Used

- JavaScript
- Node.js
- Express.js
- MongoDB
- EJS
